# 日线突破策略（实盘版）

> 确认日期：2026-11-03。选股按日线突破，买入优先级按 10 日涨幅排名强→弱，大盘用"10 日线 + 顶底分型确认"新规则，止损资金冻结到下周一。

## 一、每日流程

1. **15:05 收盘后**（服务器定时任务）运行 `python stock_check_xinlang.py`：
   - 先输出深证成指的仓位建议（`sz_market_action()`）：当前仓位、下一日仓位与开盘操作、原因、下一日收盘要关注的价位；
   - 再跑选股（`screen_new_high_breakout_sina()`），输出 `stock_result/result_sina_{时间戳}.csv`，**按「买入顺序」从上往下买**；
   - 主机名不含 `houjie-`（即服务器上）时发邮件：标题「操作建议」，正文为大盘建议，附件为股票池 csv。本地运行不发。
2. 大盘建议只是仓位建议，**选股照常输出**；大盘数据拉取失败也不影响选股和发邮件。
3. 盘中运行时，当天未收盘的 K 线不参与判断，另附一行"按当前价收盘的预估"。

## 二、选股条件（日线，`screen_new_high_breakout_sina`）

以最新交易日为突破日，全部满足才入选：

| # | 条件 |
|---|---|
| 1 | 新高：收盘价 ≥ 前 100 个交易日（不含当日）最高价 |
| 2 | 最多连续 2 日新高（只要首日突破 / 突破第二日），昨日和前日都新高的剔除 |
| 3 | 近 2 日涨幅 < 20%（当日收盘对比 3 个交易日前收盘） |
| 4 | 收红：收盘价 > 开盘价 × 1.01 |
| 5 | K 线形态，满足任一剔除：收绿、涨幅 ≤ 1%（相对昨收）、收在 (最高+最低)/2 以下、上影 ≥ 实体 |
| 6 | 倍量：当日成交额 ≥ 前 5 个交易日成交额均值 × 1.5 |

**买入优先级**：10 日涨幅排名强→弱（全市场名次，第 1 名最强）。仓位有限，每天从「买入顺序」1 开始买，买满为止。信号只在下一交易日开盘有效，过期作废。

## 三、大盘仓位（深证成指 399001，只看收盘，不看盘中）

**分型**：相邻 3 根 K 线，不做包含处理，第 3 根收盘确认。
- 底分型：中间 K 线的最高、最低都低于左右两根；
- 顶分型：中间 K 线的最高、最低都高于左右两根。

**10 日线规则**
- 收盘站上 10 日线 → 次日开盘 40%；次日收盘仍在线上 → 第三日开盘 100%。
- 收盘跌破 10 日线 → 当天停止新开、加仓、补仓，次交易日集合竞价清空，转为空仓。

**底分型（第 3 根收盘在 10 日线下才按底分型处理）**
- 以第 3 根收盘价为弱势线，收盘低于它算跌破。
- 第二日收盘未跌破 → 第三日开盘 40%；第三日收盘未跌破 → 第四日开盘 100%；第二日就跌破 → 本次底分型作废。
- 持仓期间在 10 日线下：不受 10 日线清仓约束，收盘跌破弱势线 → 次日开盘清仓。
- 收盘站上 10 日线后 → 改按 10 日线规则。

**顶分型（有持仓时出现即处理，不论在 10 日线上下）**
- 以第 3 根收盘价为参考，收盘高于它算顶分失效。
- 第二日收盘失效 → 不处理；未失效 → 第三日开盘清仓。
- 清仓后：收盘突破分型顶点（中间 K 线最高价）且在 10 日线上 → 按 10 日线规则重新进场；若先收盘跌破 10 日线 → 空仓，等站上 10 日线或新底分型。

## 四、个股规则

- **每只固定 1 层（10%）**，40% 仓位最多 4 只，100% 最多 10 只。周五不开新仓；一字涨停买不进。
- **单票止损**：max(昨日 MA5 × 0.99，昨日最低价 × 0.99)，盘中触及就清仓。
- **新开票走弱**：开仓当天和下一交易日，尾盘需同时满足"当日高点 > 昨日高点"和"收盘 > 昨日收盘"，少一项尾盘退出。
- **网格止盈**：网格步长 = 14 日 ATR% × 1.2，买价每涨一格卖 1/4，共 4 份。
- **资金冻结（一直生效）**：网格卖出的资金第二日开盘可开新仓；止损 / 走弱清仓的资金统一留到下周一开仓；大盘规则清仓的资金不冻结。

## 五、回测结果

数据：baostock 前复权日线，2018-10 ~ 2026-11（1954 个交易日），5469 只股票（**含退市股**），ST 按信号当日状态剔除；已扣手续费（买万 3、卖万 8）。

| 方案 | 总收益 | 年化 | 最大回撤 | 夏普 | 个股成功率 |
|---|---|---|---|---|---|
| **日线 + 10 日涨幅强→弱（实盘）** | **+259%** | **17.2%** | **−14.6%** | **1.34** | 44.7% |
| 日线 + RPS120 高→低 | +169% | 13.1% | −11.7% | 1.15 | 44.1% |
| 周线（买点1-W2/W3/买点2）+ RPS120 高→低 | +60% | 6.0% | −27.2% | 0.60 | 30.6% |
| 深证成指持有 | +46% | 4.8% | −50.1% | 0.32 | — |

实盘方案逐年：2018（10 月起）−4.2%，2019 +19.5%，2020 +42.2%，2021 +27.7%，**2022 −6.2%（指数 −25.9%）**，**2023 +0.6%（指数 −13.5%）**，2024 +5.8%，2025 +23.3%，**2026 +40.2%（指数 −18.6%）**。

**规则取舍依据（同一方案对比）**

| 对比项 | 年化 / 最大回撤 | 结论 |
|---|---|---|
| 新规则 + 冻结到周一 | 17.2% / −14.6% | 采用 |
| 新规则 + 冻结 1 天 | 13.8% / −30.8% | 不用 |
| 新规则 + 不冻结 | 17.4% / −30.8% | 回撤翻倍，不用 |
| 旧规则（底分型不确认、无顶分型）+ 冻结到周一 | 15.0% / −21.3% | 被新规则替代 |
| 无大盘择时 + 冻结到周一 | 3.9% / −54.1% | 大盘择时必须要 |

**样本外检验**：规则和排序是在 2024-08 ~ 2026-11 上挑出来的；在没参与挑选的 2018-10 ~ 2024-07 上，实盘方案年化 11.7%、最大回撤 −14.6%（同期指数年化 1.9%、回撤 −50.1%）。**实际预期按年化 10%~15%、最大回撤 15% 左右看。**

**已知短板与局限**
- 急涨行情跟不上：10 日线确认前就涨完了（如 2019、2024-09），只吃到指数涨幅的一部分。
- 日线无法区分同日先触及止损还是网格，回测按先止损处理（偏保守）。
- 周线方案长期无优势（2021~2023 连续三年亏损），只作参考，不占仓位。

## 六、代码与数据

| 文件 | 用途 |
|---|---|
| `stock_check_xinlang.py` | **实盘**：日线选股、`sz_market_action()` 大盘仓位、发邮件 |
| `forward_track.py` | **前向跟踪**：从 2026-11-03 起按实盘规则模拟到最新交易日，和实际账户对比（见第七节） |
| `backtest_long_run.py` | 长周期回测入口：4 套方案 × 规则 / 冻结对比，输出 `stock_result/long_*.csv` |
| `backtest_weekly_portfolio.py` | 回测引擎：数据加载、周线信号、大盘仓位（`market_levels_v2` 与实盘逐日一致）、组合模拟 |
| `backtest_daily_portfolio.py` | 日线突破信号提取（同 `screen_new_high_breakout_sina` 条件） |
| `fetch_daily_long_bs.py` | 拉 baostock 长周期日线到 `cache_bs_long/`，断点续跑 |
| `proxy_bs.py` | baostock 用的 SOCKS5 静态代理账密（不提交） |

**数据目录（都不提交，本地保留）**：`cache/`（stock_screener 周线/日线）、`cache_sina/`（新浪日线选股缓存）、`cache_sina_long/`（新浪 1500 天日线）、`cache_bs_long/`（baostock 2018 起前复权日线 + 选股信号缓存 `_weekly_signals.pkl` / `_daily_breakout_signals.pkl`）。改了选股条件后，删掉对应的信号缓存再跑回测。

**注意**
- **baostock 只能单连接串行**：多进程并发会被拉黑（`10001011 黑名单用户`，按 IP 封）。本机 IP 已被封过，长数据通过 `proxy_bs.py` 的 3 个代理各开 1 条连接拉取。
- 回测输出 `stock_result/backtest_*.csv`、`long_*.csv`、`report_*.csv` 不提交。

## 七、前向跟踪（2026-11-03 起）

`python forward_track.py`，收盘 15:10 后、跑完当天选股再运行（复用 `cache_sina` 的新浪日线，和实盘选股同源）。

- 从 `START = "2026-11-03"` 开盘起，严格按本文规则模拟：每日信号次日开盘按 10 日涨幅排名买、大盘新规则、止损 / 走弱 / 网格、止损资金冻结到下周一。
- 输出：
  - 每日：大盘目标仓位、策略总资产（模拟本金 `CAPITAL`，默认 80 万，只影响金额）、当日 / 累计收益、深证成指累计；
  - 当前模拟持仓：买入价、剩余仓位、浮盈、**明日止损价**、**下一格卖价**；
  - 已平仓交易：买入 / 清仓日、清仓原因、收益。
  - 保存为 `stock_result/forward_equity.csv`、`forward_trades.csv`。
- **和实际对比**：每天收盘后在 `stock_result/actual_account.csv`（列：`日期,总资产`）追加一行实际总资产，第一行作为基准，程序会多出「实际累计%」「差值(实际-策略)%」两列。
- 新浪日 K 不复权，跟踪期间个股除权会有少量偏差。
- `forward_*.csv` 和 `actual_account.csv` 不提交。

## 八、代码使用说明

环境：`~/venv/python3-forcrawl`（pandas / numpy / requests / chinese_calendar / baostock / yagmail / PySocks）。以下命令都在 `stock/` 目录下执行，`python` 指该环境的解释器。

### 1. 每日实盘：`stock_check_xinlang.py`

```bash
python stock_check_xinlang.py main
```

- 不带参数也一样执行 `main()`：大盘仓位建议 → 日线选股 → 服务器上发邮件。
- **运行时间**：收盘 15:10 后。之前运行时，当天未收盘的 K 线不参与判断：选股用前一交易日，大盘额外附"按当前价收盘的预估"。
- **输出**：
  - 终端打印大盘近 15 日的分型 / 仓位表和最新建议；
  - `stock_result/result_sina_{时间戳}.csv`：股票池，第一列「买入顺序」，从 1 开始买。
- **发邮件**：主机名不含 `houjie-` 才发（服务器发、本地不发）。收件人、SMTP 配置在 `send_mail_advice()` 里。
- **单独调用**（在 Python 里 `from stock_check_xinlang import ...`）：

| 函数 | 作用 |
|---|---|
| `sz_market_action(show_days=15)` | 只看大盘：当前仓位、下一日仓位与开盘操作、原因、下一日收盘关注价位 |
| `screen_new_high_breakout_sina()` | 只跑选股，返回 DataFrame，csv 路径在 `.attrs["fname"]` |
| `calc_buy_price_sina(code, date)` | 某股某日的参考买入价：max(MA5×0.99, 最低价×0.99) |
| `check_stock(code)` | 周线持仓检查（放量 / 缩量淘汰规则），周线体系遗留，可参考 |
| `send_mail_advice(summary, file_dirs)` | 手动发一封操作建议邮件 |

- **缓存**：日线缓存在 `cache_sina/`，按最新交易日判断新鲜度，盘中不写缓存；股票列表缓存 1 天。**不要手动清缓存**，全量重拉很慢。

### 2. 前向跟踪：`forward_track.py`

```bash
python forward_track.py
```

- 在跑完当天 `stock_check_xinlang.py` 之后运行，复用刚更新的 `cache_sina`。
- 可改的参数在文件顶部：
  - `START`：跟踪起始日，默认 `"2026-11-03"`；
  - `CAPITAL`：模拟本金，只影响金额；
  - `PRIORITY`：买入优先级。
- 和实际对比：每天收盘后在 `stock_result/actual_account.csv` 追加一行，例如 `2026-11-03,800000`。
- 输出：
  - 终端打印每日表、当前持仓（含明日止损价、下一格卖价）、已平仓交易；
  - 文件：`stock_result/forward_equity.csv`、`forward_trades.csv`。

### 3. 长周期回测：`backtest_long_run.py`

```bash
python backtest_long_run.py > stock_result/long_run.log 2>&1
```

- 用 `cache_bs_long/`（baostock 前复权，2018 起，含退市股）跑：
  - 4 套方案：周线 / 日线 × RPS120 高→低 / 10 日涨幅强→弱；
  - 每套 × 5 种规则：新规则冻结到周一 / 冻结 1 天 / 不冻结、旧规则、无大盘择时；
  - 基准：深证成指持有。
- **耗时**：首次约 30 分钟（提取信号），之后约 5 分钟。
- **输出**：
  - `stock_result/long_summary.csv`（汇总）、`long_yearly.csv`（逐年）、`long_equity.csv`（每日权益曲线）；
  - `long_<方案>_trades.csv`（新规则 + 冻结到周一的逐笔交易）。
- **改了选股条件后**，要删掉信号缓存再跑：`rm cache_bs_long/_weekly_signals.pkl cache_bs_long/_daily_breakout_signals.pkl`。
  - 日线条件来自 `stock_check_xinlang._check_breakout_sina`；
  - 周线条件来自 `stock_screener.CFG` / `check_buy_point_1/2`。
- **想测别的规则**：在 `backtest_long_run.py` 的 `variants` / `plans` 里加组合。
  - 可调的参数都在 `backtest_weekly_portfolio.py`：`run_portfolio()` 的 `use_freeze`（`True` = 到下周一，整数 N = 冻结 N 天，`False` = 不冻结）、`priority`（见 `PRIORITIES`）、`pool_mode`；
  - `market_levels_v2()` 的 `bottom_confirm`、`top_mode`；
  - 文件顶部的 `LAYER`（单票仓位）、`GRID_MULT` / `GRID_PARTS`（网格）、`BUY_FEE` / `SELL_FEE`（费率）。

### 4. 更新长周期数据：`fetch_daily_long_bs.py`

```bash
python fetch_daily_long_bs.py
```

- 走 `proxy_bs.py` 里的 3 个 SOCKS5 代理，每个代理一个进程、单连接串行，每次请求间隔 `REQ_DELAY = 0.5` 秒。
  - 某个代理被拉黑会自动停掉该进程；
  - 全量约 2.5 小时。
- **已存在的文件会跳过**（断点续跑），所以：
  - 要把数据更新到最新日期，先删旧数据：`rm cache_bs_long/s[hz]_*.pkl`；
  - 要刷新股票列表（新股 / 退市），再删 `cache_bs_long/_stock_list.pkl`；
  - 更新完别忘了删信号缓存（见上一节）。
- `proxy_bs.py` 格式：`PROXIES = [{"host", "port", "user", "pwd"}, ...]`，换代理改这里。
- **严禁**不走代理多进程并发请求 baostock，否则会按 IP 拉黑。
