# 突破策略（实盘版）：周线 + 日线合并池

> 确认日期：2026-11-03。
> - 候选池：周线（买点1-W2 / 买点1-W3 / 买点2）+ 日线（连续 ≥ 2 日新高）合并；
> - 买入：按 RPS120 高→低优先，开盘涨幅 > 7% 不买；
> - 大盘：**深证综指（399106）** 10 日线 + 顶 / 底分型确认（11-03 由深证成指改为深证综指，与博主一致）；
> - 资金：止损资金冻结到下周一；严格按 T+1 执行。

## 一、每日流程

### 1. 定时任务（服务器）

| 时间 | 命令 | 说明 |
|---|---|---|
| 周一 ~ 周四 15:30 | `python stock_check_xinlang.py main` | 复用周五生成的周线信号，日线数据用新浪当天收盘 |
| 周五 19:00 | `python stock_check_xinlang.py main` | baostock 17:30 后才有本周周线，会自动先跑一次周线选股 |

### 2. `main()` 执行顺序

1. **大盘仓位建议**（`sz_market_action`）：当前仓位、下一日仓位与开盘操作、原因、下一日收盘关注价位。
2. **周线选股**（`stock_screener.main`）：**每周只跑一次**。只有下一交易日股票池要用的那一周信号还没生成时才跑，正常就是周五 19:00 那次。
   - 周五休市的周：周四 15:30 时 baostock 还没本周数据，会提示，并在下次运行（下周一）时补跑。
   - 本地自动走代理，服务器直连。
3. **前复权**（`_sina_qfq_market`）：新浪日线是不复权价，用新浪复权因子把全市场转成前复权，与回测（baostock 前复权）同口径。之后的日线选股、RPS120、10 日排名、周线留池判断、前向跟踪都用前复权价。
   - 复权因子每只一个请求（约 0.55 秒/只），缓存在 `cache_sina/qfq_*.pkl`，只在除权时变：
     - 每天：用实时行情的"昨收"和日线前一日收盘对比，不一致即当天除权，只重拉这些（一般几只到几十只）；
     - 漏跑补齐：`cache_sina/qfq_checked.txt` 记录缓存覆盖到哪个交易日；中间有没跑的交易日（本地偶尔跑一次时），缓存日期早于前一交易日的都重拉，最旧优先、每次最多 1500 只，补齐前不前移覆盖日；
     - 周五：顺带刷新超过 30 天的缓存（每次最多 1500 只），再兜一层底；
     - 无缓存的每次最多补拉 800 只，**首次部署先跑一次 `python stock_check_xinlang.py qfq_init`**（全量约 50 分钟）。
   - 前复权后最新一天的价格 = 实际价格，股票池里的前收、开盘买入价上限不受影响。
   - 周线突破价是信号周五 baostock 的前复权价，如果之后除权，按复权因子换算到当前口径再比较。
4. **日线选股**（`screen_new_high_breakout_sina`）：连续 ≥ 2 日新高。
5. **前向跟踪**（`forward_track.main`）：按实盘规则模拟账户，输出模拟持仓和每只的「下一日盘中清仓价」。
6. **合并股票池**（`build_buy_pool`）：生成 `stock_result/pool_{下一交易日}.csv`。
7. **发邮件**（只在服务器发，主机名不含 `houjie-`）：
   - 标题：「操作建议」；
   - 正文：大盘建议、前向跟踪收益、今日模拟平仓、明日开盘卖出、股票池说明、明日最多新开只数；
   - 附件：股票池 `pool_*.csv`、持仓操作 `forward_holdings_*.csv`。

任一步出错不影响后续步骤，邮件正文会写明错误。

### 3. 每天要做的操作（券商端）

| 时间 | 操作 |
|---|---|
| **9:15 ~ 9:25 集合竞价** | ① 大盘提示"集合竞价全部清仓"时全部卖出；② 持仓 csv 里「下一日操作 = 开盘卖出」的卖出；③ 按股票池「买入顺序」买入：价格挂「开盘买入价上限」（前收 × 1.07），数量用「1 层参考股数」，买到大盘目标仓位或资金用完为止，备注里写"不买"的跳过 |
| 买入当天 | 网格按股票池里的「网格步长%」设好：以成交价为基准，**只卖不买**，分 4 份，之后不改 |
| 盘中 | 盘中清仓条件单：价格用持仓 csv 的「下一日盘中清仓价」，**每天更新一次** |
| **14:55 尾盘** | 买入后的第二个交易日：当日高点 ≤ 昨日高点，或现价 ≤ 昨日收盘，就卖出 |

## 二、选股与买入

### 1. 周线信号（`stock_screener.py`）

- 只取 **买点1-W2、买点1-W3、买点2**。买点1-W1 和买点3（W1 中成交额 ≥ 3 倍）不进候选池：回测里买点3 只在 2024 年后有效，加入合并池后 2018~2024 年化从 10.6% 降到 7.6%。
- 周五收盘出信号，**下周一到周四**有效。
- 前一日收盘跌破突破价的剔除（买点1 的突破价是 W1 收盘价，买点2 是前高）。
- 信号存在 `stock_result/weekly_signals.csv`（信号周、代码、名称、信号类型、突破价、ATR%、网格步长%），每周追加。

### 2. 日线信号（`screen_new_high_breakout_sina`）

范围：沪深 A 股，**不含北交所**（回测 baostock 和周线选股都没有北交所；RPS120、10 日排名的全市场分布也不含）。以最新交易日为突破日，全部满足才入选：

| # | 条件 |
|---|---|
| 1 | 新高：收盘价 ≥ 前 100 个交易日（不含当日）最高价 |
| 2 | **连续 ≥ 2 日新高**（今天和昨天都是新高），之前连续多少天不管 |
| 3 | 近 2 日涨幅 < 20%（当日收盘对比 3 个交易日前收盘） |
| 4 | 收红：收盘价 > 开盘价 × 1.01 |
| 5 | K 线形态，满足任一剔除：收绿、涨幅 ≤ 1%、收在 (最高 + 最低) / 2 以下、上影 ≥ 实体 |
| 6 | 倍量：当日成交额 ≥ 前 5 个交易日成交额均值 × 1.5 |

信号只在**下一交易日开盘**有效。

### 3. 合并股票池与开盘买入

- **候选**：本周有效的周线信号 + 前一交易日的日线信号。同一只票两边都有，只算一次。
- **排序**：RPS120 高→低（一位小数）；RPS120 相同时按 10 日涨幅弱→强（排名数字大的在前）。回测同分弱→强 22.6%/−19.5%，强→弱 21.7%/−21.2%，差距小，主要是让顺序固定。RPS120 = 120 日涨幅在全市场的百分位，全市场都用前复权价。取值日：周线票固定用信号周五收盘（周一~周四不变），日线票用信号日收盘，与回测、前向跟踪一致（回测对比见 backtest_rank_refresh.py：合并池固定周五 22.6%，每日重算 20.8%）。股票池里同时附上 10 日涨幅排名。
- **跳过**：
  - 开盘涨幅 > 7%（集合竞价挂单价 = 前收 × 1.07，不超过涨停价）；
  - 已持有的；
  - **本周已买过又卖掉的**；
  - 周线信号前收跌破突破价的；
  - ST 和停牌的。
- **每只 1 层**：前一交易日收盘时总资产（持仓 + 现金 + 冻结资金）的 10%，按整手取整（科创板 ≥ 200 股），买不起一手的跳过。
- **可买只数**：以下三条里最严的那个。
  - 大盘目标仓位（40% → 4 层，70% → 7 层，100% → 10 层；网格卖出部分后按剩余比例计层）；
  - 可用资金至少 1 层（冻结资金不算）；
  - 候选数量。
- **周五和大盘清仓日不开新仓。**

## 三、大盘仓位（深证综指 399106，只看收盘，不看盘中）

指数选择：博主「一戈168」用的是深证综指。长周期回测里，深证综指比深证成指（399001）年化高约 3 个点、夏普 1.40 对 1.24，合并池、周线、日线三种候选池方向一致；代价是 2021 年和 2026-01 更差，最大回撤略大。

**首日仓位**：下面"次日开盘 40%"的首日建仓，如果开仓信号当天（站上 10 日线 / 底分型确认那天）深证综指涨幅 **> 3%**，改为 **70%**，其余不变（`FIRST_LV` / `STRONG_UP_PCT` / `STRONG_UP_LV`）。回测：2018 年以来只出现 10 次，其中 9 次第二天加满；合并池年化 22.6% → 23.6%，回撤 −19.5% → −19.6%，两段区间同向改善。首日一律重仓反而变差（7 层 20.7% / −22.2%），见 `backtest_first_level.py`。

**分型**：相邻 3 根 K 线，不做包含处理，第 3 根收盘确认。底分型 = 中间 K 线的最高、最低都低于左右两根；顶分型反之。

**10 日线**
- 收盘站上 → 次日开盘 40%；次日收盘仍在线上 → 第三日开盘 100%。
- 收盘跌破 → 当天停止新开、加仓、补仓，次交易日集合竞价清空，转为空仓。

**底分型（第 3 根收盘在 10 日线下才按底分型处理）**
- 以第 3 根收盘价为弱势线，收盘低于它算跌破。
- 第二日收盘未跌破 → 第三日开盘 40%；第三日收盘未跌破 → 第四日开盘 100%；第二日就跌破 → 本次作废。
- 持仓期间在 10 日线下：不受 10 日线清仓约束，收盘跌破弱势线 → 次日开盘清仓。站上 10 日线后改按 10 日线规则。

**顶分型（有持仓时出现即处理）**
- 以第 3 根收盘价为参考，收盘高于它算顶分失效。
- 第二日收盘失效 → 不处理；未失效 → 第三日开盘清仓。
- 清仓后：收盘突破分型顶点（中间 K 线最高价）且在 10 日线上 → 按 10 日线规则重新进场。若先收盘跌破 10 日线 → 空仓，等站上 10 日线或新底分型。

## 四、卖出与资金规则

| 规则 | 内容 |
|---|---|
| **T+1** | 买入当天不能卖：当天盘中触及止损或尾盘走弱 → **次日集合竞价卖出**；当天碰到的网格不成交，次日照常 |
| **单票止损** | max(昨日 MA5 × 0.99，昨日最低价 × 0.99)，按前复权价算，盘中触及就清仓；开盘已低于止损价按开盘价卖 |
| **新开票走弱** | 买入后的第二个交易日（买入当天的走弱由 T+1 顺延到次日开盘），尾盘要同时满足"当日高点 > 昨日高点"和"收盘 > 昨日收盘"，少一项就尾盘退出 |
| **网格止盈** | 步长 = 信号日 14 日 ATR% × 1.2，以买入价为基准每涨一格卖 1/4（整手），共 4 份，只卖不买 |
| **大盘清仓** | 次交易日集合竞价全部卖出 |
| **跌停 / 停牌** | 卖不出的顺延到下一交易日开盘 |
| **资金冻结** | 网格卖出的资金第二日开盘可开新仓；止损 / 走弱清仓的资金冻结到**下周一**；大盘清仓资金不冻结 |

## 五、实盘执行要求（回测假设，偏离会显著影响收益）

每笔交易平均只赚 0.5% 左右，**成交价每偏差 0.1% 都会吃掉一大块利润**：

- **买入一律走集合竞价**，挂前收 × 1.07 的限价单，按开盘价成交。开盘后再追买，突破股往往已经涨上去了。
- T+1 次日卖出、大盘清仓也走集合竞价。
- 网格用限价单（券商自动网格），挂在网格价上。
- 盘中止损用条件单。回测按止损价下浮 0.2% 成交，0.5% 时年化约降 1.5 个点。
- 尾盘走弱在 14:55 左右判断并卖出。回测按收盘价下浮 0.1% 成交。
- 实测费率（财通证券对账单）：买入约万 1.35，卖出约万 6.35（含印花税万 5），没有最低 5 元。

### 主要结论与取舍过程

1. **T+1 是决定性因素**：原来允许当天卖出时，日线"首日突破"方案年化 17%。加上 T+1 后只剩 3.7%（2018 ~ 2024 为负），因为买入当天走弱的票第二天开盘平均还要多亏 2.3%。周线方案反而从 6% 升到 13.6%，因为 T+1 减少了被盘中波动洗出去的次数。
2. **日线只做连续 ≥ 2 日新高**：剔除只突破 1 天的，日线方案年化从 2.4% 提高到 8.4%。连续 ≥ 3 日信号太少（每天不到 2 个），反而变差。
3. **周线 + 日线合并**：两类信号重合只有 6.5%，合并后候选更充足，年化最高（深证成指口径 18.4%，深证综指口径 21.6%），高于各自单独使用。
4. **RPS120 高→低优于 10 日涨幅强→弱**：在 T+1 下各方案都是如此。
5. **开盘涨幅限制**（深证成指口径）：4% / 5% 太严（年化 15.2% / 16.1%）；6% / 7% 最好且接近（18.3% / 18.4%）；7% 在 2018 ~ 2024 段略好。
6. **大盘择时必须要**：去掉后年化 2.8%、回撤 −41%。新规则（底 / 顶分型次日确认）明显好于旧规则（深证综指口径 21.6% vs 12.6%）。
7. **大盘指数用深证综指**：比深证成指年化高约 3 个点（21.6% vs 18.4%），两段都更好。
8. **止损资金冻结到下周一**：不冻结年化略高但回撤更大、2018 ~ 2024 段更差。
9. **成交方式**：集合竞价 / 限价不加滑点、止损 0.2%、尾盘 0.1% 时，结论不变；若集合竞价也有 0.1% 滑点，年化降到约 11%。

### 已知短板

- 急涨行情跟不上：10 日线确认前就涨完了（如 2019、2024-09），只吃到一部分。
- 日线数据无法区分同日先触及止损还是网格，回测按先止损处理（偏保守）。

## 九、代码使用说明

环境：`~/venv/python3-forcrawl`（pandas / numpy / requests / chinese_calendar / baostock / yagmail / PySocks）。以下命令都在 `stock/` 目录执行。

### 1. 每日实盘

```bash
python stock_check_xinlang.py main
```

- 周一 ~ 周四 15:30、周五 19:00 运行。
- 单独调用（`from stock_check_xinlang import ...`）：

| 函数 | 作用 |
|---|---|
| `sz_market_action(show_days=15)` | 只看大盘 |
| `screen_new_high_breakout_sina(min_consec=2, max_consec=None)` | 只跑日线选股，返回 DataFrame |
| `build_buy_pool(market, daily_sig, sim)` | 生成合并股票池（`market = _sina_qfq_market(_sina_load_market())`，前复权） |
| `qfq_init()` / `python stock_check_xinlang.py qfq_init` | 首次全量拉复权因子缓存（约 50 分钟） |
| `calc_buy_price_sina(code, date)` | 某股某日 max(MA5 × 0.99, 最低 × 0.99)（前复权），即次日盘中清仓价 |
| `send_mail_advice(summary, file_dirs)` | 手动发邮件 |

- **不要手动清缓存**：`cache_sina/` 日线按最新交易日判断新鲜度，股票列表缓存 1 天且拉不全不写缓存。

### 2. 周线选股（一般不用手动跑）

```bash
python stock_screener.py
```

- `main()` 会在需要时自动调用。手动跑要在周五 17:30 后。
- 本地自动走代理（本机 IP 已被 baostock 拉黑），服务器直连。
- 只用单连接串行，**严禁多进程并发**。

### 3. 前向跟踪

```bash
python forward_track.py
```

- 顶部参数：`START`（起始日）、`CAPITAL`（本金）、`PRIORITY`、`REAL`（实盘约束）。

### 4. 长周期回测

```bash
python backtest_long_run.py > stock_result/long_run.log 2>&1
```

- 约 5 分钟（信号缓存已存在时；首次提取约 30 分钟）。
- 改了选股条件后，删掉 `cache_bs_long/_weekly_signals.pkl`、`cache_bs_long/_daily_breakout_signals*.pkl` 再跑。
- 可调参数在 `backtest_weekly_portfolio.py`：
  - `run_portfolio()` 的 `use_freeze`（`True` = 到下周一 / 整数 N = 冻结 N 天 / `False` = 不冻结）、`priority`、`pool_mode`（`weekly` / `daily` / `mixed`）、`real`（实盘约束，见 `REAL_DEFAULT`：本金、各类滑点、费率、`max_open_gap`）；
  - `market_levels_v2()` 的 `bottom_confirm` / `top_mode`；
  - 文件顶部的 `LAYER`、`GRID_MULT` / `GRID_PARTS`、`BP3_VOL_RATIO`。

### 5. 更新长周期数据

```bash
python fetch_daily_long_bs.py
```

- 走 `proxy_bs.py` 的 3 个 SOCKS5 代理，每个代理一个进程、单连接、间隔 0.5 秒，全量约 2.5 小时。
- 已存在的文件会跳过。要更新到最新日期，先删 `cache_bs_long/s[hz]_*.pkl`（要刷新股票列表再删 `_stock_list.pkl`），更新后删掉信号缓存再回测。
