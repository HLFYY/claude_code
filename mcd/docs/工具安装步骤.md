# IDA-NO-MCP + reverse-skills 安装步骤

## 前置要求

- ✅ IDA Pro 7.0+ (已安装)
- ✅ Python 3.6+ (已安装)
- ✅ Node.js 16+ (已安装)
- ✅ npx (已安装)

---

## 安装步骤

### 1. 克隆工具仓库

```bash
# 创建工具目录
mkdir -p ~/Desktop/ai_code/mcp_js/app_reverse_tool
cd ~/Desktop/ai_code/mcp_js/app_reverse_tool

# 克隆 IDA-NO-MCP
git clone https://github.com/P4nda0s/IDA-NO-MCP.git

# 克隆 reverse-skills
git clone https://github.com/P4nda0s/reverse-skills.git
```

### 2. 安装 reverse-skills (全局)

```bash
npx skills add P4nda0s/reverse-skills --global
```

**结果**: 8 个技能安装到 `~/.agents/skills/`

```
✓ ~/.agents/skills/rev-symbol        # 符号分析
✓ ~/.agents/skills/rev-struct        # 数据结构重建
✓ ~/.agents/skills/rev-frida         # Frida Hook 脚本生成
✓ ~/.agents/skills/rev-idapython     # IDAPython 参考
✓ ~/.agents/skills/rev-dex-dumper    # DEX dump
✓ ~/.agents/skills/rev-unicorn-debug # Unicorn 模拟
✓ ~/.agents/skills/rev-u3d-dump      # Unity IL2CPP
✓ ~/.agents/skills/rev-ios-dump      # iOS 砸壳
```

### 3. 配置 IDA 插件

```bash
# 创建插件目录
mkdir -p ~/.idapro/plugins

# 创建软链接
ln -sf ~/Desktop/ai_code/mcp_js/app_reverse_tool/IDA-NO-MCP/oldpython/INP.py \
       ~/.idapro/plugins/INP.py
```

## 使用方法

### IDA-NO-MCP

```bash
# GUI 导出 (推荐)
open -a "IDA Professional 9.1" file.so
# 等待分析完成 → 按 Cmd-Shift-E → 选择输出目录

# 命令行导出
/Applications/IDA\ Professional\ 9.1.app/Contents/MacOS/idat \
    -A \
    -S"$HOME/.idapro/plugins/INP.py ~/output 0 auto" \
    file.so
```

**导出结果**:
```
output/
├── AGENTS.md              # AI 友好的总览
├── decompile/             # 所有函数的反编译代码
├── functions.json         # 函数索引
├── strings.json           # 字符串列表
└── callgraph.dot          # 调用图
```

### reverse-skills

在任意目录打开 Claude Code，输入:

```bash
# 符号分析
/rev-symbol --target "SecBox|aesKey|signKey"

# 数据结构重建
/rev-struct --address 0xEB6E4

# 生成 Frida Hook 脚本
/rev-frida --function "JniLib0.cV"

# 查看 IDAPython 参考
/rev-idapython --topic "函数分析"
```

## 故障排查

### IDA 插件无法加载

```bash
# 检查软链接
ls -lh ~/.idapro/plugins/INP.py

# 重新创建
rm ~/.idapro/plugins/INP.py
ln -sf ~/Desktop/ai_code/mcp_js/app_reverse_tool/IDA-NO-MCP/oldpython/INP.py \
       ~/.idapro/plugins/INP.py

# 重启 IDA
killall ida64
```

### reverse-skills 不可用

```bash
# 检查安装
ls -la ~/.agents/skills/ | grep rev-

# 重新安装
npx skills add P4nda0s/reverse-skills --global

# 重启 Claude Code
```
